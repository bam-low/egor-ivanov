# egor-ivanov

Личный сайт-портфолио Егора Иванова — веб-дизайнер и Tilda-разработчик.

Статический сайт без сборки: `index.html`, `styles.css`, `main.js`, `avatar.js`.
3D-персонаж собран на Three.js (подгружается с CDN jsDelivr).

## Запуск локально

```bash
python3 -m http.server 8000
# открыть http://localhost:8000
```

Открывать через локальный сервер: при двойном клике по `index.html` браузер не загрузит модули.

## Что заполнить

- **Контакты** — блок `#contact` в `index.html`: Telegram, почта, ссылка на профиль Kwork.
- **Работы** — блок `#works` сейчас помечен «Неактивно». Когда появятся кейсы, заменить заглушки `.work__media` на изображения и убрать классы/стили неактивности.
- **Аватар** — сейчас стоит временная процедурная заглушка. Итоговый аватар подключается атрибутом `data-avatar` у `.hero__stage` в `index.html`:
  - `data-avatar="assets/avatar.png"` — картинка (PNG/WebP **без фона**), плавает и наклоняется за курсором;
  - `data-avatar="assets/avatar.glb"` — 3D-модель, поворачивается к курсору; если файл не загрузится, покажется заглушка.
