# Сайт-портфолио Егора Иванова

Статический сайт без сборки: `index.html`, `styles.css`, `main.js`, `avatar.js`.
**Кэш:** подключаемые файлы в `index.html` помечены версией (`styles.css?v=9`, `main.js?v=9`, `avatar.js?v=9`, `assets/avatar.webp?v=9`). При каждом изменении этих файлов увеличивать номер `v` везде, иначе у посетителей новый HTML окажется со старыми стилями из кэша.

Язык сайта — русский. Стиль: тёмный фон, крупная жирная типографика (Unbounded), акценты лайм `#d4ff3f` и фиолетовый `#7c5cff`, стеклянные карточки, кнопки-пилюли. Современно, «чувствуется уровень», но без перегруза.

## Аватар
- Никаких фото лица — вместо него персонаж в стиле Pixar: молодой парень, симпатичный, **без бороды**.
- Текущий аватар — `assets/avatar.webp` (сгенерированная картинка без фона: парень в фиолетовом худи с лаймовыми наушниками), подключён через `data-avatar` у `.hero__stage`. Заказчику нравится фиолетовое свечение вокруг персонажа.
- Процедурный персонаж в `avatar.js` — только запасной вариант, если картинка не задана.
