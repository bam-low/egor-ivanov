# Сайт-портфолио Егора Иванова

Статический сайт без сборки: `index.html`, `styles.css`, `main.js`, `avatar.js`, `brief.js` (форма заявки). `worker/` — Cloudflare Worker, пересылающий заявки в Telegram (инструкция в `worker/README.md`).
**Кэш:** подключаемые файлы в `index.html` помечены версией (`styles.css?v=20`, `main.js?v=20`, `avatar.js?v=20`, `brief.js?v=20`, картинки — и `VER` в `main.js`). При каждом изменении этих файлов увеличивать номер `v` везде, иначе у посетителей новый HTML окажется со старыми стилями из кэша.

Язык сайта — русский. Стиль: тёмный фон, крупная жирная типографика (Unbounded), акценты лайм `#d4ff3f` и фиолетовый `#7c5cff`, стеклянные карточки, кнопки-пилюли. Современно, «чувствуется уровень», но без перегруза.

## Публикация
- Сайт: **https://ivanovdev.site/** — GitHub Pages из `main` (репозиторий открытый: закрытый на бесплатном тарифе отключает Pages), свой домен через файл `CNAME`. Старый адрес https://bam-low.github.io/egor-ivanov/ GitHub сам перенаправляет на домен.
- DNS у регистратора: 4 записи `A` для `@` → 185.199.108.153 / .109.153 / .110.153 / .111.153 (по желанию `AAAA` 2606:50c0:8000::153 … 8003::153), `CNAME` для `www` → `bam-low.github.io`. HTTPS — галочка Enforce HTTPS в Settings → Pages.
- Превью ссылки — `assets/og.jpg` (1200×630) + og-метатеги в `<head>`; `canonical`, `og:url`, `og:image`, `robots.txt`, `sitemap.xml` указывают на https://ivanovdev.site/ — при смене домена поменять везде (и `CNAME`, и `ALLOWED_ORIGIN`).

## Аватар
- Никаких фото лица — вместо него персонаж в стиле Pixar: молодой парень, симпатичный, **без бороды**.
- Текущий аватар — `assets/avatar.webp` + `assets/avatar.avif` (`data-avatar-avif`) (сгенерированная картинка без фона: парень в фиолетовом худи с лаймовыми наушниками), подключён через `data-avatar` у `.hero__stage`. Заказчику нравится фиолетовое свечение вокруг персонажа.
- Процедурный персонаж в `avatar.js` — только запасной вариант, если картинка не задана.
