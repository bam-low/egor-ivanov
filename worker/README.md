# Воркер сайта: уведомления и анонимная статистика в Telegram

Форма «Обсудить проект» на сайте — помощник: она собирает из ответов готовое сообщение,
а человек сам отправляет его в Telegram или на Kwork. Сайт ответы никуда не отправляет.

Этот воркер нужен только для уведомления: когда человек нажимает «Открыть Telegram» или «Открыть Kwork»,
сайт присылает сюда одно слово (`telegram` или `kwork`), а воркер пишет вам в Telegram:
«👀 Кто-то на сайте собрал сообщение и открыл Telegram».

**Никаких данных о человеке:** ни имени, ни текста, ни контактов. IP-адрес не сохраняется и не пересылается
(лимит — общий на весь сайт, журнал запросов в Cloudflare выключен). Поэтому 152-ФЗ здесь не затрагивается.

## Статистика посещений
На каждой странице (`<body data-page="…" data-stats="адрес воркера">`) `main.js` отправляет одно сообщение:
какая страница (`home` / `portfolio`), откуда пришли — только категория (Яндекс, Google, Telegram, ВКонтакте, Kwork,
напрямую, другие сайты), телефон или компьютер и новое ли посещение (первый просмотр в этой вкладке).
Ни IP, ни cookies, ни адресов — 152-ФЗ не затрагивается.

- Счётчики за день хранятся в KV (привязка `STATS`; хранилище Cloudflare создаёт само при первой выкладке), 400 дней.
- Каждое утро в 9:00 по Москве бот присылает сводку за вчера, по понедельникам — ещё и за неделю.
- Роботы (поисковики, автотесты) не считаются. Свои заходы можно исключить: открыть сайт один раз с `?nostat`
  в конце адреса (`https://ivanovdev.site/?nostat`) — этот браузер больше не считается; `?stat` — вернуть.
- Цифры приблизительные: «посещение» — открытая вкладка, людей без cookies не различить.
  Бесплатный лимит KV — 1000 записей в день, то есть до ~1000 просмотров в день; защита от накрутки — 60 просмотров в минуту.

## Настройки (уже сделаны)
- Воркер `egor-ivanov` подключён к репозиторию через Cloudflare Workers Builds, **Root directory**: `worker`.
  Cloudflare сам выкладывает его при каждом изменении в `main`; настройки — в `worker/wrangler.toml`.
- Секреты в Cloudflare → воркер → **Settings → Variables and Secrets** (тип **Secret**):
  - `BOT_TOKEN` — токен бота от [@BotFather](https://t.me/BotFather);
  - `CHAT_ID` — ваш id от [@userinfobot](https://t.me/userinfobot). У бота должна быть нажата **Start**.
- `ALLOWED_ORIGIN` (в `wrangler.toml`) — адреса сайта, с которых принимаются уведомления.
  При смене домена дописать новый через запятую.
- Адрес воркера вписан в `data-notify` у формы в `index.html`.

## Защита от накрутки
- Принимаются только запросы с адресов из `ALLOWED_ORIGIN` и только слова `telegram` / `kwork`.
- Не больше 10 уведомлений в минуту на весь сайт (`FORM_LIMIT` в `wrangler.toml`).
- Одно уведомление на одно собранное сообщение (повторные нажатия не считаются).

## Как выключить
Очистить `data-notify` у формы в `index.html` — сайт перестанет присылать сигнал. Воркер можно удалить в Cloudflare.
